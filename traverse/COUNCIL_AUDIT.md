# Callweave Contract Council Audit — 2026-08-11

## Method

The review follows the LLM Council shape: independent role-based first opinions, cross-review against authoritative Traverse/UMA contract rules, and a single implementation synthesis. It is a structured design review, not a claim that several external LLM providers were invoked.

## Council findings and adopted improvements

| Perspective | Finding | Severity | Adopted improvement |
|---|---|---:|---|
| Bioacoustician | Classification evidence must never be confused with verified wildlife truth. | High | `acoustics-classify` returns evidence only; `detection-resolve` is deterministic; `observation-manage` requires review. |
| Local-first architect | Generic contracts lacked an explicit local-state boundary. | High | Added `state_schema`, sandboxed host-adapter declarations, idempotency keys, and local-first policy on every capability. |
| Runtime engineer | Draft contracts incorrectly claimed passed validation evidence. | High | Removed all draft evidence claims. Validation evidence is produced only after a real Traverse validation/publish path. |
| Runtime engineer | Unhappy-path examples did not contain facts that would cause their declared result. | High | Added strict `runtime_context` input state. Each invalid-input, dependency-unavailable, and policy-denied example now carries the matching condition. |
| UMA architecture reviewer | The prior graph had no declared event edges, risking hidden workflow coupling. | High | Added 15 versioned draft domain-event contracts and explicit publisher/subscriber references. |
| Privacy reviewer | Speech/privacy review must precede an external LMM handoff. | High | `privacy-protect` emits `privacy.protected`; `review-prepare` consumes it and fails closed under denied policy. |
| Wildlife-data steward | Range filters can hide rare/range-shift evidence. | Medium | `detection-resolve` preserves a surprising state and `unknown-organize` retains evidence. |
| Operations engineer | Model/host work could drift into ambient provider access. | Medium | Model downloads, device access, storage, and external inference are declared host boundaries; future packages cannot hard-code providers. |
| Artist/product designer | The daily artwork could hide uncertainty. | Medium | `daily-create` consumes observation, unknown, and knowledge facts and keeps deterministic uncertainty-aware mapping in P0. |

## Residual gaps deliberately deferred

1. No capability package or WASM binary exists yet; all capability and event contracts remain `draft`.
2. Persona records are local staging records. They must be published to the target Traverse registry before a registry-aware capability publish can resolve `persona_ref` values.
3. Connector contracts and host implementations for audio capture, storage, source discovery, model caching, and external LMM submission are not yet authored. The contract boundaries are declared; executable adapters are a future implementation milestone.
4. A full workflow definition is deferred until the P0 capability packages exist. The event contracts already make all intended progression visible without pretending the packages can execute.
5. Local model licensing, artifact conversion, browser memory/throughput, and ultrasonic hardware compatibility require implementation-time validation.

## Council release gate

Do not change a Callweave contract/event from `draft` to `active` until all of the following exist:

- corresponding WASM package and reproducible digest;
- contract and event validation evidence generated by Traverse;
- use-case runtime fixtures for every output enum path;
- target-registry persona resolution;
- connector requirements/host adapter implementation for every declared exception;
- local model/license evidence where an implementation classifies audio;
- privacy test proving speech and precise location are excluded from review packages.
